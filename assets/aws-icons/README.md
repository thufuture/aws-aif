AWS Architecture Icons

These selected SVGs reproduce service tiles from the AWS Architecture Icons set. Their artwork is © Amazon Web Services, Inc. and is subject to the AWS icon terms. The files are sourced from the AWS icon artwork bundled in @aws-icons/svg 4.1.1; only icons used by this study app are included.

Official icon page and terms: https://aws.amazon.com/architecture/icons/
Source package: https://www.npmjs.com/package/@aws-icons/svg

Mapping notes:
- Bedrock sub-features reuse the Amazon Bedrock tile because the set does not provide separate Knowledge Bases, Agents, or Guardrails tiles.
- Trainium and Inferentia cards use the EC2 tile to show their EC2 instance context; those accelerators do not have a separate tile in this icon set.
